# Portfolio Notes

## My focus

I use this project to talk about system behaviour across services: where latency originates, how trace context flows, how a release can be scoped to one service, and how a platform team prevents configuration drift.

## Evidence I can show

- `helm-chart/` and `kubernetes-manifests/` for packaging and runtime definitions.
- `terraform/` for the GCP infrastructure example.
- OpenTelemetry-related configuration for trace and metric discussions.

## Known boundary

The application source is upstream. My portfolio contribution is the engineering analysis, deployment validation, source attribution, and the ability to explain the platform and operational trade-offs accurately.
